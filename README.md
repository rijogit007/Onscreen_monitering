# 🎓 Onscreen Monitoring System

An AI-powered online examination platform with real-time onscreen monitoring and facial tracking built using **React**, **Django**, and **Face API**.

---

# 🚀 Features

- 🔐 JWT Authentication System
- 📧 Email OTP Verification
- 👨‍💼 Admin & Student Dashboards
- 📝 Online Exam Management
- 🤖 AI-Based Face Monitoring
- 📷 Webcam Detection & Tracking
- ⚠️ Suspicious Activity Detection
- 🌐 Full Stack React + Django Application
- 🎨 Modern Animated UI
- 🔒 Protected Routes

---

# 🛠️ Technologies Used

## 🎨 Frontend

- React 19.x
- Vite
- React Router DOM v7
- Axios
- Framer Motion
- Three.js
- @react-three/fiber
- @react-three/drei
- @vladmandic/face-api

---

## ⚙️ Backend

- Django 6.0.5
- Django REST Framework
- Simple JWT Authentication
- SQLite Database
- Django CORS Headers
- Google SMTP
